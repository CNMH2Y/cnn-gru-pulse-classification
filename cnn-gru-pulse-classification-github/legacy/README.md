# Original experimental script

`gru_exm.py` is the earlier pulse-processing and CNN-GRU training prototype. It is retained for context and is not a validated entry point for this source release.

The file includes unused imports, commented experiments, a local relative dataset path, and an old checkpoint filename. Its commented comparison-chart values are manually specified plotting constants. The plotted training loss multiplied by 100 is not classification accuracy. Neither should be used as evidence of held-out performance.

Use `src/` for the modular implementation. No raw recordings or weights are included.
